# Датчики и камеры

`SensorCatalog::load("catalog/sensors")` читает файлы `<id>.toml`. Имя файла совпадает
с `id`. Для своей позиции укажите `id`, `name`, `kind` и таблицу `[model]`.
Паспорт `[passport]` можно приложить отдельно. Числа в паспортах хранятся в исходных
единицах. Паспортный предел точности или плотность шума сами по себе не задают
дисперсию отдельного отсчёта.

Каждый параметр модели задаётся таблицей `{ value = ..., provenance = "...", source = "..." }`
либо строкой `"unknown"`. Виды происхождения — `datasheet`, `vendor`, `paper`,
`measured`, `derived`, `estimate`. Неизвестный обязательный параметр приводит
к ошибке установки. Для оценок, данных продавца и полей `CompiledSensor.params`
без происхождения установка добавляет упрощение, которое блокирует положительное
доказательство. Поля `params` переопределяют числа из `model`.

## Общие параметры

| Поле | Смысл |
|---|---|
| `rate_hz` | Целая частота в Гц. Начало измерений — нулевой такт |
| `latency_s` | Задержка измерения после окончания сбора данных, с |
| `bias`, `noise_std` | Постоянное смещение и СКО белого гауссовского шума в единицах выхода |
| `drift_per_s`, `drift_rw_std` | Линейный дрейф в единицах выхода за секунду и коэффициент случайного блуждания в единицах выхода на √с |
| `quantum` | Шаг округления после прибавления ошибок. Ноль выключает квантование |
| `saturation`, `min`, `max` | 0 выключает насыщение. При 1 обязательны обе границы. Ограничение применяется после квантования |
| `drop_probability` | Вероятность пропуска одного отсчёта или кадра |
| `fault` | 0 — штатно, 1 — залипание последнего показания, 2 — обрыв, 3 — ступенчатое смещение |
| `fault_at_s`, `fault_offset` | Начало отказа для ненулевого `fault` и величина ступеньки для режима 3 |

У IMU для гироскопа отдельные `gyro_noise_std`, `gyro_bias`, `gyro_drift_per_s`,
`gyro_drift_rw_std`, `gyro_quantum`, `gyro_saturation`. Условия для
`gyro_min`, `gyro_max` и `gyro_fault_offset` такие же, как у основных полей.
Случайное блуждание ведётся отдельно по осям. У камеры дрейф общий для кадра,
белый шум независим по пикселям и цветовым каналам. Единица цвета в конвейере —
доля полной шкалы RGB, единица глубины — метр.

Для пространственных типов обязательны `mount_dx_m`, `mount_dy_m`,
`mount_dz_m`, `mount_roll_rad`, `mount_pitch_rad`, `mount_yaw_rad`.
Поправка позы применяется в номинальном кадре датчика, в порядке неподвижных
осей X, Y, Z для углов. Поза датчика в описании мира относится к телу или миру.

## Источники и выходы

| `kind` | Источник, дополнительные поля и выход |
|---|---|
| `encoder` | Координата `joint` в рад или м. `encoder_zero` задаёт вычитаемый сдвиг. `encoder_mode` — 0 прямая координата, 1 абсолютная шкала по модулю `encoder_period`, 2 отсчёт от первого измерения. Выход `value` |
| `current` | `<drive>/current_a`, выход `value` в А |
| `temperature` | `<drive>/winding_c`, выход `value` в °C |
| `bridge_adc` | Опубликованное напряжение моста `<drive>/bridge_mv`, выход `value` в мВ |
| `imu` | Удельная сила a−g в м/с² (`x`, `y`, `z`) и угловая скорость в рад/с (`gx`, `gy`, `gz`), обе в кадре датчика |
| `force`, `torque` | Реакция родительского соединения на установленное тело. Момент отнесён к точке датчика. Выходы `x`, `y`, `z` в Н или Н·м |
| `pressure`, `touch` | Сумма нормальных сил в точках контакта тела внутри `patch_radius_m` от точки датчика. Для давления делится на `patch_area_m2`; для касания сравнивается с `touch_threshold_n`. Выход `value` в Па или как 0/1 |
| `rangefinder` | Луч MuJoCo вдоль +Z датчика. Дальности вне `range_min_m`…`range_max_m` и отсутствие пересечения дают недействительный `value` |
| `color_camera`, `depth_camera` | Выходы `image` (RGB8) и `depth` (DepthMm16) соответственно |

В абсолютном режиме поправки, шум и дрейф сворачиваются вместе с координатой
в интервал `[0, encoder_period)`. Квантование может перенести отсчёт через
верхнюю границу обратно в начало цикла. Границы насыщения должны лежать
в пределах цикла.

До первой публикации канала привода, при пропуске, обрыве и залипании
`valid = false`. При залипании сохраняется последнее действительное
содержимое, включая исходный `captured` кадра. `Observation::latest` возвращает
последнее действительное показание даже после отказа. Для решения по свежести
проверяйте последний `Sample` в `Observation.samples`, включая его `at`
и `valid`. `Sample.at` содержит время доставки. У действительного скалярного
отсчёта запланированное время замера равно `at` минус настроенная задержка.
Между тактами физики используется последнее состояние физики. Для несовпадающих
сеток тактов установка добавляет `blocks_proof: true`. У кадра проверяйте
`captured`, `at` и `valid`. Нулевая глубина означает дыру.

## Оптика и время

Обеим камерам нужны `width`, `height`, `fx`, `fy`, `cx`, `cy`, `k1`, `k2`,
`k3`, `p1`, `p2`, `near_m`, `far_m`, `exposure_s`, `readout_s` и
`exposure_samples`. Оси кадра — X вправо, Y вниз, Z вперёд. Центр первого
пикселя — (0.5, 0.5). Глубина — расстояние по Z. Цвет дополнительно требует
`ambient` (долю фонового освещения) и `spatial_samples` (число проб вдоль
одной стороны пикселя). Глубина требует `hole_probability`.

Нулевой `readout_s` задаёт общий затвор. Иначе это разница времени старта
экспозиции первой и последней строки. Растеризатор усредняет пробы в серединах
равных частей экспозиции и интерполирует позы тел по соседним тактам физики.
Поза геометрии вычисляется из интерполированной позы тела и локального крепления.
Доставка — начало кадра плюс считывание, экспозиция и задержка либо первый
такт физики, на котором готовы данные, если этот такт наступит позже.
Времена, заданные в секундах, округляются вверх до наносекунды. Обрыв и
залипание к концу сбора данных делают кадр недействительным. Ступенчатое
смещение применяется по времени начала кадра.
Частота кадров не превышает частоту физики. Недопустимая оптика или превышение
лимита памяти и числа проб дают ошибку конфигурации.

Мишень из `checkerboard` можно поместить в `visual` обычного предмета или среды и
сериализовать в файл мира. В MJCF для плоских поверхностей поддерживается также
цветовая 2D-текстура материала. Полупрозрачность, тени, отражения и отклик
реальной камеры за пределами модели. Любая камера добавляет `blocks_proof: true`.

Оценщик создаёт `FrameTruthReader` из `SensorHandle::frame_truth_reader()` и вызывает
`advance(&Truth)` на каждом такте физики того же прогона, начиная с нулевого.
Идентификатор канала и `available` связывают результат с попыткой съёмки по
`ImageFrame.at`. Для действительного кадра также совпадает `captured`.
Глубина и идентификатор
геометрии соответствуют центру пикселя в середине экспозиции его строки. Позы
соответствуют `reference_at`, середине полного интервала кадра; сравнивать
внешнюю оценку следует в мировых координатах на тот же момент.
