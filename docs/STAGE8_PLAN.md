# Этап 8. Окно платформы

1. Подключить окно к штатному `sim-cli` и журналу `sim-runtime`. Запуск и оценка остаются в конвейере. Окно читает вердикт, причины и ключ худшей строки отчёта.
2. Воспроизводить позы на целочисленной шкале журнала. Загружать мир через `sim-world`; для совместной сцены подставлять геометрию участника из данных. Остановить воспроизведение при несовпадении схемы координат.
3. Использовать общий программный рендер в экранную текстуру. Добавить обзор, вид из места установки датчика, показания и записанные кадры, векторы доступных сил и сравнение журналов на одной отметке времени.
4. Вынести список контрольных входов и параметры демонстрации в `devices/stage8`. Приёмка проходит по тому же пути, что окно, без создания окна. Сохранять временные кадры на начало, середину и доступное положение худшего случая. Сверять объект по буферу идентификаторов, проекцию отдельно и длину стрелок с журналом.
5. Проверить журналы побайтно, отсутствие записей, ошибки разбора и отрицательные статусы. Отдельно перечислить ограничения выгрузки штатного конвейера.
