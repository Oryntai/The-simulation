# Инженерная приёмка этапа 8

Исправления курсора внесены, этап ожидает повторную проверку. Для худшей
строки каждой из семи сборок курсор берёт событие оценщика из привязанного дочернего
журнала. При пустой отметке окно открывает запись на нуле и сообщает, что оценщик
не записал событие. Диагностические ряды доступны при просмотре.

Тест Workshop `худшие_строки_кампании_открываются_в_трёх_текстурах_без_окна`
читает `worst_run_key` из `devices/stage6.toml` для всех семи сборок. Он сверяет
привязки, 21 текстуру и семь пар SIMLOG. Тест CLI отдельно отвергает подмену времени
события и проверяет пустую отметку при наличии диагностического максимума ряда.
В прогоне после исправлений пять строк открылись на событии оценщика. У строк 05
и 07 событие отсутствовало. Все семь пар журналов совпали побайтно.

Для штатного сценария `sim-run --campaign MANIFEST --repeat KEY --view ARCHIVE` выгружает тот же живой журнал, который использует оценщик. Клиент сверяет ключ, отпечатки входов и журнала, режим и горизонт. На [новом блоке](../devices/stage8/acceptance/campaign.toml) клиент открыл `Rejected` на 4 000 000 нс. Ход 14 мкм при пределе 8 мкм совпал с независимой суммой четырёх шагов Euler.

Ниже зафиксирована первая проверка до выгрузки точной модели и повтора штатного сценария.

```sh
cargo run --offline -p workshop -- --suite devices/stage8/suite.json
cargo run --offline -p workshop -- --platform devices/stage8/rod-world.toml --duration 0.08
RUST_TEST_NOCAPTURE=1 cargo test --offline -p workshop
cargo test --offline -p sim-verify --test platform_boundary
```

Оба теста используют заданный `CARGO_TARGET_DIR`. Проверка окна загружает программные текстуры без создания окна и сохраняет обзорные кадры только во временный каталог.

Сверены 21 кадр, 23 пространственных вектора и 8 полос скалярных сигналов в ньютонах. Координаты поз сверены побитово с журналом. Стрелка показывает реакцию на второй геом со стороны первого в позе на левой границе интегрирования. В отчётах всех семи задач исход `not_analyzed`. Ни один из них не содержит `worst_time_ns`.

В трёх сценах участник движется по данным журнала. Тест сравнил по три позы пар опор из `fit.json` с вычисленными смещениями по касательной и бинормали. Наибольшее расхождение 4,163·10⁻¹⁷ м. Изменение положений монтажных точек по трём сцепленным сценам составило до 1,944 / 3,034 / 81,427 мм. Эта сверка относится к номинальным контактным точкам модели. Фактическая посадка, давление и пригодность для носки требуют измерений.

## Время, датчики и вердикт

- На независимом стержне с шагом 1 мс курсор 37 000 003 нс использовал позу от 37 000 000 нс. Сдвиг 7,03 мм совпал с суммой шагов Euler, камера находилась на X = 132,03 мм. В текстуре на 24 мс появился RGB 96×72 с началом захвата в 0. При сравнении запись Б закончилась на 30 мс, а её кадр и значение исчезли на общем курсоре 37 000 003 нс. Полоса в 24 пикселя на четверти шкалы сохранила исходные пиксели кадра.
- Стержень открывается обычным `--platform` из двух TOML. На отдельном блоке клиент и прямой вызов CLI выдали 35 845 одинаковых байт SIMLOG и 2 317 байт JSON. Высота после 100 шагов по 1 мс составила 0,9495 м. У семи задач совпали отпечатки журналов при повторных запусках.
- В короткой кампании из `decision-campaign.toml` сборка `exceeded` получает `Rejected`, а `estimated` и `bounded` получают `NotProven`. Ступень `bounded` остаётся `NeedsWork`, поскольку для подтверждения прочности нужен стендовый замер.
- Поле окна «Файл заверенных замеров (необязательно)» соответствует `sim-run --campaign … --measurements …`. Повтор отчёта, запущенного в окне, берёт пути исходного запуска. Для прочности установка должна задать ревизию и проверку измеренного канала.
- Отдельный протокольный тест окна показывает `Rejected`, `NotProven` и `PassedSimulation/BenchOnly` в одной кампании. В её временной копии для `bounded` имитируется пакет регистратора этой ревизии по двум посадкам. Синтетический ряд 750 кПа сверяется с формулой изгиба при пределе установки 5 МПа. Импорт отклоняет журнал с типом `synthetic` и пакет другой ревизии. Для физической сборки требуется натурный замер.
- Переход к худшему событию проверен на связанной отметке 37 000 003 нс. Вариант, горизонт и наличие отметки проверяются до изменения курсора. Для семи штатных задач доступен диагностический просмотр. `--repeat` в короткой кампании вернул ту же худшую строку и отпечаток её входов. Журнал и отметка события отсутствуют.

## Что пока открыто по §4.11

  и независимой калибровки.
