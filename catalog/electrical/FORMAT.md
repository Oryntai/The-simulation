# Электрические данные, формат 1

`sim_cli::electrical::load_catalog` читает файлы TOML из каталога в порядке пути.
Позиция однозначно определяется ключом в `parts`. Каталог включает параметризуемые
позиции и синтетические эталоны. У шаблона диапазон оставляют открытым, пока нет
обоснования для выбранной детали. В `measurement` всегда указан способ уточнения.
Числа конечные, единицы следуют из имени параметра. У диапазона обязательны
`min`, `nominal`, `max` и `source`. Источник задаётся одноэлементной таблицей
`datasheet`, `paper`, `measured`, `derived` или `estimate`. Точные синтетические
данные `derived` используются только в `scope = "reference"`.

У части есть `kind`, `source`, именованные `pins`, локальные `internal_nodes`,
поэлементный `elements` и `ratings` с условиями. Параметры примитива задаются в СИ,
выводы перечисляются по порядку MNA. Для МОП это сток, затвор, исток, подложка.
Включаемые ветви с неизвестным состоянием, неподтверждённые пределы и существенные
пробелы `model_gap` оставляют открытое доказательство.

Схема объявляет `format`, `name`, `scope`, `nets` и `components`. У каждого
вывода позиции указано имя цепи. Два вывода с общим именем соединяются явным
монтажным участком или эквивалентом компонента. У `connections` два адресованных
конца `компонент/вывод`, тип стыка, параметры сопротивления и допустимого тока
и список предшествующих операций `after`. У штекеров и гнёзд обязательно семейство,
а у ключованных пар совпадает позиция. У сигналов с относительной опорой роль
задаётся, например, `role = { signal_in = "minus" }`.

`rails` описывают точку измерения полярности питания парой «плюс, возврат»,
а `bindings` задают пары питания либо физический контакт платы и его функцию.
Сверка привязок вызывается с уже разрешёнными установщиком идентификаторами.
`check_static` оценивает схему в пределах Э1. `assembly_sheet` отдаёт монтажные
операции и измерения с условиями. Примеры с ручными исходными числами находятся
в [корпусе](../../devices/electrical/corpus/).

`crimp = true` у монтажного стыка `kind = "splice"` отмечает обжим гильзой
двух зачищенных жил. Монтажный лист показывает операцию `Crimp`; электрическая
ветвь остаётся резистивной.

Профиль живого опыта может явно задать `diagnostic_connections` с сопротивлением
`ohm`, его источником `source` и путём `parameters` от файла профиля. Сопротивление
дополняет только стыки без значения. Файл параметров версии 1 дополняет отсутствующие
числа элементов по ключу `parts.<позиция>.<элемент>.<параметр>` диапазонами с источником
`estimate`. Каноническая схема, её проверки и сборочный лист сохраняют пробелы.
В `observed_boards` перечисляются платы, для которых проверяются привязки контактов
и питания без расчёта реакции МК на напряжение.
